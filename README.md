# NillyFont Pro — Ultra-Light Native Windows 10/11 Font Manager & True Greek Glyph Filter

> **Πανάλαφρος Native Font Manager για γραφίστες & καθημερινούς χρήστες: live δοκιμή κειμένου σε όλες τις γραμματοσειρές, πραγματικό φίλτρο «Μόνο Ελληνικά» (`GetFontUnicodeRanges`), σύγκριση A vs B & Zero-Admin εγκατάσταση `.ttf/.otf`.**
> **Created by [Nilly graphics (Sotiris Christos)](https://nillygraphics.com/) · Part of the 0€ MIT [NillyGraphics Suite](https://github.com/nillynp/nillyhub)**

## Χαρακτηριστικά
- **Φίλτρο «Ω Μόνο Ελληνικά»:** Ελέγχει πραγματικά τα GDI Unicode glyph tables κάθε γραμματοσειράς (όχι ψεύτικο fallback!).
- **Live Specimen Preview:** Γράψε το δικό σου κείμενο (τίτλο, brand, αριθμούς), άλλαξε μέγεθος / Bold / Italic και δες όλες τις γραμματοσειρές σε real-time χωρίς lag.
- **Σύγκριση A vs B:** Δες 2 γραμματοσειρές δίπλα-δίπλα με πλήρες Ελληνικό & Λατινικό αλφάβητο.
- **Drag & Drop Εγκατάσταση (.ttf / .otf):** Εγκαθιστά γραμματοσειρές στα Windows 10/11 χωρίς δικαιώματα διαχειριστή (`HKCU\...\Fonts`).
- **Ultra-Light:** `~70 KB` EXE, 0 DLLs, `~6–10 MB` RAM (`TrimMemory`), 0 MB idle RAM & παράθυρο **`i`**.
